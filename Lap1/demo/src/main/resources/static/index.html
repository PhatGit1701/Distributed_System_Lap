💡 Architectural Insight: Peter Deutsch's Fallacies of Distributed Computing

Fallacy #2: "Latency is zero." In traditional web design (Task 1), relying exclusively on server-side validation forces the user interface to block and wait for a full WAN round-trip even for predictable user mistakes (e.g., malformed email or empty field).

Latency Hiding (Task 2) resolves this user-perceived delay by validating basic constraints locally in JavaScript (0ms feedback), while maintaining mandatory server-side validation as an uncompromised security boundary for valid payloads.
