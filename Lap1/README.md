# Practical Lab: Architecting Latency Hiding
> **Course / Lab**: Distributed Systems & Software Architecture  
> **Topic**: Compensating for WAN Network Latency via Client-Side Validation (Latency Hiding Pattern)

Please navigate to `demo/` directory to run tests and launch the Spring Boot application:

```bash
cd demo
.\mvnw.cmd test
.\mvnw.cmd spring-boot:run
```

Access the UI at: `http://localhost:8080`

Full documentation and step-by-step presentation guide can be found at [demo/README.md](demo/README.md).
